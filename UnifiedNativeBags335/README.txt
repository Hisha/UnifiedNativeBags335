UnifiedNativeBags335 is a conventional World of Warcraft 3.3.5a addon.

Install this directory under Interface/AddOns and enable mod-native-reagents on
the server/client build. Disable the original UnifiedBags335 addon before
loading this successor. Existing UnifiedBags335DB settings are reused.

At a banker, use Bank and Reagent Storage in the same bank window. Reagent
storage supports Deposit Reagents, Auto Deposit, full and split-stack deposits,
right-click stack withdrawal, Shift-click quantity withdrawal, and safe virtual
drag withdrawal to the inventory window.
